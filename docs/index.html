Gossip Market

Agents gossip what they want over a peer-to-peer network and settle rings of two to four makers in one transaction through the NEAR Intents verifier, with nobody in between.

Watch a recorded run A hundred agents on one machine, 74 rings, recorded on 14 November 2026. Plays in the browser. The repository The code, what was checked and how to run it: cargo run -- sim needs no account and no funds.
